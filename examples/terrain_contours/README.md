# 等高线生成地形面示例

应用入口：几何模型树右键 → **等高线地形**，或几何菜单 → 草图 → 等高线地形。

可以点击“载入山丘示例”，然后“构建地形面”；也可以导入示例工程中的 `contours.dxf`。

示例坐标单位为米：中心平面坐标为 (500000, 3000000)，外围范围约为 200 × 160 米。
输入包含闭合范围边界（高程 100）、四圈等高线（110、120、130、140）和山顶点（150）。
示例直接生成 5 个连续 CAD 曲面，每个等高带一个曲面，保留原始等高线位置和真实高程。
“预览采样间距”只控制显示与 VTP 预览精度；计算网格的单元尺寸在网格模块单独设置。
显示三角形和计算网格三角形都不会被反过来做成地形的 CAD 小面。

在“文件 → 打开工程”中选择生成的 `等高线地形示例.xml`，可以直接恢复地形几何及其参数。
工程保存全部输入坐标和 CAD 几何缓存，移动整个工程目录或移走原始 DXF 后仍可重建。
修改高程、参与对象、用途或采样长度后，旧地形立即失效，需要重新点击“构建地形面”。

用途说明：

- 等高线：同一条线上的高程必须相同，可在“高程”列统一指定。
- 范围边界：一个闭合、无自交的外边界；全部参与对象应位于范围内。
- 控制线：当前连续曲面支持闭合等高控制线；不自动分域。
- 高程点：最内圈内的单个山顶或谷底点。

非等高曲线默认不参与，可指定正确高程后勾选。连续曲面未指定范围边界时使用最外圈闭合等高线。
相交线高程冲突、同 XY 不同 Z、无效范围和未完整保留约束的结果会被拒绝。
生成结果是连续的地形曲面，支持导出 VTP 预览；传给网格器的是 CAD 曲面。
后续进入网格模块，选择“二维表面网格”并设置单元尺寸。默认按等高线分域，本例保留 5 个高程面域：
100～110、110～120、120～130、130～140、140～150。
这些面域默认使用相同材料，不能根据高程推断土层；普通草图材料分区保持独立。
也可在“面域划分”中选“整体地形面域”。开放等高线可直接用于共面区域；非共面的开放、分叉等高线需要先整理成连续区域，不再自动用三角小面替代曲面。

详细输入要求和客户文件说明见 [等高线文件与分域说明](等高线文件与分域说明.md)。

草图功能：对象捕捉默认为关闭，勾选“对象捕捉（绘制时）”后捕捉端点、中点、交点和曲线最近点。
选择和框选不会被捕捉改变位置。直线、圆弧按原几何延伸；样条沿端点切线增加线段。
曲线分割保留 CAD 参数，炸开将复合轮廓拆成独立曲线。DXF INSERT 图块在导入时递归展开。

开发验证及重新生成工程：

```powershell
python tests/run_geometry_checks.py --build-dir build/Desktop_Qt_6_7_3_MSVC2022_64bit_Release
```

客户样例附加回归：

```powershell
python tests/run_geometry_checks.py --build-dir build/Desktop_Qt_6_7_3_MSVC2022_64bit_Release --customer-dxf C:/D_Drive/m1.dxf
```

验证程序在 `build/terrain_feature_preview/example_project` 生成 XML 工程、输入 DXF、VTP 和 BREP。
同时生成独立的 Base_Gemo / Base_UiFrame / Base_Mesh DLL，不替换运行中程序占用的文件。
回归检查包含真实前处理 BREP 导出和 SMESH 二维划分，验证地形面域归属、接缝连通及网格尺寸控制。
另外会动态加载实际 Base_Gemo 插件，通过真实创建动作和页面切换检查网格入口；
即使运行时缓存缺失、仅剩曲线，或地形参数尚未打开，已构建地形仍从保存的输入恢复网格面。
临时 BREP 的 `.domains.json` 配套文件保留面域名称、几何归属及材料分组，并校验几何摘要，防止误用旧分域数据。
