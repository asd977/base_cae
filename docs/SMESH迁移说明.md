# SMESH 网格后端

网格生成入口为 `plugins/Base_Mesh/SmeshMeshGenerator`，通过动态库
`plugins/CAE_SMESHBridge.dll` 调用 standalone SALOME SMESH。

桥接实现及原生 SubMesh 调度迁自 `C:/project/CAE/code/TMSR/plugins/Base_Mesh`。
保留了该实现的三维多域计算、原生局部假设、Sweep、混合网格和边界层桥接能力。
本项目现有整体划分页面接入二维三角形/四边形为主网格、三维四面体和一阶四面体转八节点六面体；
二维开放面和二阶单元通过新增的 `cae_smesh_generate` 接口适配。

## SDK

所有 SDK 均已复制到本项目 `libs/`，运行和构建不依赖 TMSR 目录：

- `SMESH-occ-7.9.3`
- `OCC-7.9.3`
- `boost_1_84_0`（头文件及运行库）
- `pthreads-win32`
- 原有 Qt 6.7.3、VTK 9.2.6

CMake 校验 SMESH 元数据中的 OCC 版本和 TKernel.dll 的 SHA256，避免混用 SDK。
SMESH 的四面体/曲面算法依赖 `NETGENPlugin`、`nglib4smesh`；这两个库属于迁入的
SMESH SDK，必须随桥接库部署。旧的直接 nglib/ngcore 调用、独立 Netgen SDK 构建项、
Gmsh 参数转换和 `.vol` 生成/导出已删除。VTK、Nastran 导出继续可用。

局部尺寸按 CAD 子形映射到 SMESH 原生 Edge/Face/Solid SubMesh。
共形分割通过 OCC 修改历史将原实体控制映射到分割后的子形。
地形面域和材料归属、求解器数组、点/边/面边界集合写入生成的 VTK，供显示、分组和荷载选择使用。
边界集合类别统一为 `SmeshBoundary`。

## 扫掠和分级 SubMesh

“整体剖分”创建工程树中的“网格划分”父 Mesh。右击该节点可添加体、面、边 SubMesh，
以及扫掠剖分。体 SubMesh 下可继续添加面或边 SubMesh，面 SubMesh 下可继续添加边 SubMesh。
子节点中的几何选择限制在父节点范围内，参数未指定时继承父级。

- 体：尺寸上限、最小尺寸（继承/自动/指定）、细化程度、优化、曲率，
  以及“整个域”或“仅体内部”的尺寸作用范围。
- 面：尺寸上限、最小尺寸和整圆曲率分段；继承所属域的其他设置。
- 边：继承或指定最大尺寸，也可使用固定分段数和分段比例。
- 扫掠：选择体及其起始/目标面，设置扫掠层数、起始面尺寸和四边形优先。
  可预览选择和推荐端面。其余体按父级或对应体 SubMesh 的四面体参数计算。

纯四面体模式支持逐个体 SubMesh 计算，结果累积在同一个原生父 Mesh 中。
扫掠采用 TMSR 的原生混合流程，使用一阶单元整体计算，以维持共享界面的共形连接；
扫掠体的面密度由起始面尺寸及层数控制。边界层没有设置入口，也不会提交边界层请求。
所有父级参数、子级设置、几何选择和扫掠配置随工程保存、重新打开。

新增 `SmeshWorkflowChecks` 已验证分级继承、范围及重复分配检查、增量计算、
原生扫掠/四面体混合，以及混合模式中的体/面局部设置。
真实网格插件回归验证了工程树菜单、分级配置和扫掠设置的保存恢复。

## 扫掠分块与交互迁移（2026-10-27）

补入 TMSR 的 `MeshSmeshPartitionWidget`、图形拾取及批量扫掠任务流程。
在网格工具栏、整体剖分右键菜单或扫掠页面的“分块设置”进入。
选择目标实体，可用 X/Y/Z 坐标切面、已有平面或两条平行直边确定切面；
支持切面增删、修改、启停、分块预览与分块点选。

分块使用临时 OCC 副本，原始 CAD 不变。实际剖分使用相同的切面规则，
通过布尔历史将原有体、面、边尺寸设置传递给分块结果，并保留原始材料分域。
分块选择通过几何签名对应到工作 BREP，不将预览 Region/Face 编号直接当作 SMESH 编号。
改变切面会清空原扫掠区域列表，保留尺寸编辑值，要求在新拓扑上重新选择。
切面、任务列表、层数和尺寸均随网格节点保存；旧版单体扫掠设置仍可读取。

扫掠页面用图形区选择区域并识别兼容方向：唯一方向自动配对端面，多个方向在
“扫掠方向”下拉框选择；仍支持手动点选端面。区域可加入同一任务表，
也可批量添加几何体或当前全部分块。任务表缩减为区域、状态、层数、尺寸四列。
直接点击“生成网格”会保存当前有效区域，并生成该父网格。
边界层入口与配置没有迁入。

工作流桥接接口为 ABI 15，以传递“六面体优先 / 严格扫掠”的选择。
本轮按用户要求停止模型测试，只进行编译检查；上文回归结果属于此前版本。

## 整体剖分参数与扫掠范围

整体剖分支持自动最小尺寸和保留的手动最小尺寸、六级精细度（含自定义）、
曲率自适应、生成后优化、尺寸增长率、每边分段密度、每曲率半径分段。
这些参数经工作线程传给 SMESH；自定义参数也适用于二维表面及扫掠混合中的四面体区域。
标准精细度沿用原生预设，修改曲率半径分段会切换为自定义。
自动最小尺寸向后端传入零，保存工程时仍保留手动数值；旧工程按原来的非零最小尺寸和 0–1 精细度恢复。

体网格尺寸设置允许包含扫掠体。生成时先确认扫掠所属的最终 OCC 分块，
将这些分块从体四面体设置中扣除，扫掠的起始面尺寸和层数保持独立。
体设置作用于其余四面体区域；同一个体重复分配给多个扫掠任务仍会报错。
包含扫掠时，“应用并生成网格”会整体重建父网格，避免单体增量计算破坏共享界面。
